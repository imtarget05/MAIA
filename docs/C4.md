# MAIA — C4 Architecture

> Source of truth: `MAIA/README.md` (Hybrid RAG + Agent Pipeline diagram).
> Workflow: `Find → Understand → Cite → Act`.
>
> **Two deployment profiles exist; this document shows both. They are NOT interchangeable.**
> - **Local Dev / Demo**: FastEmbed (384-dim) + Qdrant (local container) + PostgreSQL checkpoints
> - **Azure Production** (`ca-maia-api.wittysand-b748274c.eastasia.azurecontainerapps.io`):
>   Cloudflare Workers AI embeddings (1024-dim, `@cf/baai/bge-m3`) + Qdrant Cloud + PostgreSQL
>
> **G-MAIA-01 — CLOSED.** The LangGraph durable graph used `SqliteSaver` in both profiles,
> on ACA ephemeral disk, so checkpoints did not survive scale-in/out. It now uses
> `PostgresSaver` in `get_durable_graph()` — the same function `POST /agent/chat` calls —
> configured via `DATABASE_URL`. The served path is proven across two real OS processes by
> `docs/_p9_served_path_probe.py` + `tests/test_served_path_durability.py`, and it fails
> closed rather than falling back to a local file.
>
> The subtlety worth keeping in mind: this repo had an `AsyncPostgresSaver` in
> `persistence.py` and a restart probe proving it worked, while the served path still ran on
> SQLite. The capability existed; the runtime did not use it. `persistence.py` is now
> labelled PROBE-ONLY rather than deleted, so there is one wired authority instead of two
> candidates.
>
> Remaining and explicitly NOT claimed: Azure multi-replica behaviour is
> `LOCAL_MULTI_PROCESS_RUNTIME_VERIFIED` only. See `docs/adr/0006-*` for the limitation
> boundary on the answerability gate.

## C4-Container (Local Dev Profile)

> This profile runs with `MAIA_LLM_PROVIDER=mock`, `VECTOR_STORE_BACKEND=qdrant` (local Docker),
> `AUTH_DB_URL=sqlite:///./maia.db`. Used by `scripts/run_demo_e2e.sh`.

```mermaid
C4Container
    title MAIA — Containers (Local Dev)
    Person(emp, "Employee", "HTTP client / curl")
    Container_Boundary(m, "MAIA (Local)") {
        Container(api, "FastAPI backend", "Python", "/chat, /agent/chat, /auth, /ingest")
        Container(rag, "Hybrid retrieval", "Qdrant local + BM25 + RRF k=60", "gate >= 0.3, rerank, cite")
        Container(agent, "LangGraph agent", "StateGraph + SQLite ckpt (ephemeral)", "slot-fill, interrupt/resume")
        ContainerDb(db, "SQLite", "file: maia.db", "auth, sessions, checkpoints (lost on restart)")
        ContainerDb(qdrant, "Qdrant (Docker)", "localhost:6333", "dense vectors")
    }
    Rel(emp, api, "calls", "HTTP")
    Rel(api, rag, "retrieves", "in-process")
    Rel(api, agent, "executes actions", "in-process")
    Rel(agent, db, "checkpoints", "SQL (ephemeral)")
    Rel(rag, qdrant, "vector search", "gRPC")
```

## C4-Container (Azure Production Profile)

> Verified at `ca-maia-api.wittysand-b748274c.eastasia.azurecontainerapps.io` on 2026-10-02.
> See `docs/evidence/MAIA_AZURE_LIVE_PROOF.md` for 16/16 checks PASS.
>
> **Differences from local dev:**
> - Embeddings: Cloudflare Workers AI `@cf/baai/bge-m3` (1024-dim), not FastEmbed (384-dim)
> - Vector DB: Qdrant Cloud, not local container
> - LLM: Cloudflare Workers AI Llama 3.1-8B, not mock
> - Auth DB: SQLite on ACA ephemeral filesystem (checkpoints lost on restart — see KNOWN_LIMITATION above)
> - Streamlit UI: NOT deployed on Azure (REST API only via HTTP)
