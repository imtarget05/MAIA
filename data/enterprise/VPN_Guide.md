# VPN Guide v1.8 — IT Department

## Section 1: What is VPN
VPN allows secure remote access to company internal networks.

## Section 2: How to Request VPN
Employees can request VPN by asking MAIA "cách request VPN" or via IT portal (vpn.company.com). Provide employee ID and business justification. Approval is typically within 2 hours for active employees. MAIA can create a VPN request ticket via `create_it_ticket(type="vpn_request")`.

## Section 3: Installation
Download client from vpn.company.com, install, and login with SSO. Configuration file is auto-provisioned.

## Section 4: Troubleshooting
If VPN fails, check internet, restart client, or contact #it-help. Common error "Authentication failed" means SSO token expired.

## Section 5: Security
Do not share VPN credentials. Disconnect when not in use.
